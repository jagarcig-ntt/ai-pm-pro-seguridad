## 1. Problema / necesidad
La teoría se escribió el 21-oct para el demo FeedbackHub en Cloudflare Pages, con forks y el squad en el centro. Desde entonces ha cambiado la sesión:
- cada alumno practica sobre su producto de Lovable, solo con navegador;
- el demo es `feedback-hub` en Cloudflare Workers;
- staging y producción comparten datos;
- el squad es opcional.

Quedan unas 90 líneas desactualizadas, entre las versiones de alumnos, las de formador y el glosario.
